# مسار السيارات — نسخة ويب قابلة للتثبيت (PWA)

## المزايا الموجودة
- واجهة عربية RTL مناسبة للجوال.
- تسجيل السيارات ورقم اللوحة والهيكل والجهة المالكة والموقع والحالة والملاحظات.
- تخزين محلي في المتصفح باستخدام IndexedDB، مع حفظ صور الاستلام والحركات.
- سجل حركة: من/إلى، نوع النقل، الناقل، رقم السطحة، الملاحظات والصور.
- بحث وتصفية حسب الموقع.
- تصدير تقرير CSV يفتح في Excel.
- نسخة احتياطية JSON تشمل بيانات السيارات وسجل الحركات والصور، مع الاستعادة.
- Service Worker لتخزين ملفات التطبيق والعمل دون إنترنت بعد فتحه أول مرة من HTTPS.

## مهم قبل الاستخدام الحقيقي
- التطبيق لا يرسل البيانات إلى خادم؛ البيانات محلية على الجهاز والمتصفح الذي استُخدم.
- لا تمسح بيانات الموقع أو تحذف بيانات المتصفح، فقد تفقد السجلات المحلية.
- أنشئ نسخة احتياطية بانتظام، وجرّب استعادة نسخة على جهاز اختبار.
- ملف CSV لا يتضمن الصور؛ النسخة الاحتياطية JSON هي التي تشمل الصور.
- النموذج لا يثبت نفسه من ملف ZIP مباشرة. يلزم نشر الملفات على استضافة HTTPS مجانية ثم فتح الرابط عبر Chrome واختيار «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- لا توجد بيانات تجريبية افتراضية في النسخة الفعلية لتجنب الخلط مع بيانات السيارات الحقيقية.

## نشر مجاني مقترح عبر GitHub Pages
1. أنشئ مستودع GitHub جديدًا (Public) باسم مثل `masar-cars`.
2. ارفع محتويات هذا المجلد إلى جذر المستودع، وليس ملف ZIP نفسه.
3. من Settings > Pages اختر النشر من فرع `main` ومجلد `/(root)`.
4. انتظر رابط HTTPS الذي يظهر في صفحة Pages.
5. افتح الرابط في Chrome على أندرويد، وافتح القائمة ⋮ ثم «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
6. افتح التطبيق مرة واحدة مع الإنترنت، وبعد تحميله يمكن استخدامه دون اتصال.

## ملاحظات تقنية
- Service Worker يتطلب سياقًا آمنًا (HTTPS أو localhost).
- حدود التخزين المحلي تختلف باختلاف الجهاز والمتصفح. صور كثيرة قد تستهلك مساحة ملحوظة.
- لا يوجد تسجيل دخول أو مزامنة بين أجهزة؛ النسخ الاحتياطي والاستعادة هما وسيلة النقل بين الأجهزة.
